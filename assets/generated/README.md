# Generated assets (development only)

Media generated with fal.ai during development lives here (or uses a `gen-` filename prefix).

Rules (from the MVP plan):

- **Development only.** fal.ai is never called by the product at runtime. No fal.ai client in `backend/` or `apps/web/`, no fal.ai key in staging or production.
- **No real data in prompts.** Invented content only. Never customer data, user content or secrets.
- **Mark and replace.** Track every file in the table below. Anything shipped must follow the Look & feel rules. Launch marketing visuals are real screenshots and recordings of real runs.
- Check fal.ai's terms and the model's license before using an asset in public material.
